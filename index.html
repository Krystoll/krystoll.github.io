Калькулятор ущерба от пожара

Модель системной динамики последствий пожаров на промышленных предприятиях: статистика МЧС России за 2015–2022 гг., матрица причинно-следственных связей, квадратичные полиномы, система дифференциальных уравнений и выбор плана мероприятий по критерию минимума целевой функции.

Переменные нормированы на максимум за 2015–2022 гг. · t = (год − 2015)/10
  1. ДанныеСтатистика X₁–X₁₅ нормируется: X̃ = X / X_max.
  2. Связи и полиномыПо матрице связей (+1 / −1) для каждой пары подбирается f(X̃_j) = β₀ + β₁X̃_j + β₂X̃_j².
  3. Проверка моделиСистема (3) решается методом Рунге — Кутты 4-го порядка, результат сравнивается с данными.
  4. Планы мероприятийДля каждого плана считается целевая функция; лучший план даёт минимум.

Нормированные значения X̃ = X / X_max

Значения 2015 года — начальные условия системы. Значения по годам используются для подбора полиномов и проверки модели.

Матрица причинно-следственных связей U_ij, (1)

Строка — характеристика X_i, на которую влияют; столбец — влияющая характеристика X_j или внешний фактор E_k. Щелчок по ячейке меняет значение: 0 → +1 → −1 → 0.

Система дифференциальных уравнений (2)–(3)

dX_i/dt = α_i·(1 − p_i)·∏ f_ij(X_j⁺)·ΣE⁺ − β_i·∏ f_ij(X_j⁻)·ΣE⁻. Коэффициенты α_i, β_i играют роль множителя 1/X_i^norm и подобраны МНК так, чтобы решение системы было ближе всего к данным 2015–2022 гг.; p_i — управляющее воздействие плана (0 — без мероприятий).


  
Квадратичные полиномы f_j(X̃_j) = β₀ + β₁X̃_j + β₂X̃_j²

    
Каждый полином — регрессия МНК нормированной X̃_i на X̃_j по восьми годам. R² показывает качество подгонки. Отрицательные значения полинома принимаются равными нулю.
